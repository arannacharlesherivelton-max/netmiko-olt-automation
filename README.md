# Automação de Provisionamento para ISPs (Netmiko)
Script em Python para integração com planilhas CSV e execução remota de comandos via SSH em equipamentos de rede (OLTs e roteadores).

## Funcionalidades
- Leitura em lote de dados de clientes e IPs via arquivo estruturado.
- Aplicação de regras de configuração e VLANs de forma automatizada.
- Tratamento de exceções para timeout e falhas de autenticação.

## Tecnologias
- Python
- Biblioteca Netmiko
